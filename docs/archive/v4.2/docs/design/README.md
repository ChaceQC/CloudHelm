## 2. 版本规则

1. 总体设计使用 `vM.N`，配套专题使用 `vM.N.P`；前两位必须相同。当前总体设计为 `v4.2`，详细文档为 `v4.2.0`。
2. 同一总体基线内，专题澄清、补充与修订递增第三位；可以独立递增，但同时更新下方基线清单及依赖文档的兼容说明。
3. 改变三端边界、状态所有权、安全不变量或交付语义等总体决策时，需显式评审是否升级总体版本，不以增加第三位隐藏不兼容变更。
4. 总体版本变化后，配套文档完成核对才可迁移到新的前两位，初始修订号为 0；旧文档归档，不自动批量改号假定兼容。
5. 版本写入正文页首，专题文件名保持稳定，避免修订号变化使链接失效。文档版本不等于软件发布版本、数据库版本或执行 `schema_version`。

## 3. 文档维护

修改设计规则时，同步更新负责文档、受影响引用、验收要求和版本清单。实现进度及实际验收结果在交付记录中维护，设计正文说明系统结构、行为和约束。
