## 支持边界

Git 来源导入、文件操作、根锁、候选封存、数据库权限/事务及 Docker 写入者盘点真实执行。夹具仅替代存储准入与空只读 Runner 登记，未证明物理容量或真实 Runner 管理闭环。DBOS 入队真实，未运行 worker loop、真实模型或收费出站。

离线语义通过没有客户端动作时继续查询原 human_owned 状态核对，未注入真实网络断线。回执未知仅覆盖快照完成到业务登记前中断；未覆盖真实进程崩溃、入队失败或所有存储损坏。未知 stage 仍按既有候选原身份核对，不能重新采集当前工作文件。

交还提供完整文件级 before/after 元数据和前后固定快照/commit 引用，不把源码正文或完整差异复制到模型上下文/DBOS 检查点。交还使输入与正式验收消费待复核，不自动宣布新输入有效、工作项 accepted、Task 完成或恢复 Agent 推进。查询与使用接口见[写入权说明](../../development/p2-handoffs.md)。

支持服务唯一写入者及经过核对的只读 Runner；不开放任意宿主编辑、可写 Runner 或 Desktop 本地 Git。当前开发环境的 reader binding 已变化而旧容器仍挂载时，先停止原环境再核对。未执行完整部署、容量、Desktop 编译/原生或人工验收，没有新增开发镜像。
