## 兼容与支持限制

新工具仅在新 ContextPackage 显式授予开发角色；同一 Session 的工具集合仍不可改变。当前创建要求父目录存在，补丁仅支持单个唯一旧文本的精确替换，不提供通用 patch 语法、隐式目录创建或任意命令。文本最多 64KiB，diff 正文最多 8KiB，超量和二进制保留真实标记。

秘密路径及明显秘密正文沿 A03 规则拒绝/筛选，可能拒绝含敏感字段名的普通源码，不保证识别任意未知格式。命令和工作流只传元数据/引用，写入通过既有内容暂存及物理文件日志；accepted 不等于 applied，unknown 必须沿原操作核对。修改可由原候选链固定，不表示模型已自行完成工程循环。
