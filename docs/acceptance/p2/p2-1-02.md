## 支持范围

首个长工具是当前 Task/工作项、同主体的 Workspace materialize，复用已有 P1 权限、产品来源与执行边界。费用结果按原请求追加，不改写预留历史；费用已知不证明丢失的模型输出已恢复。已保存 Run 结果可沿原身份恢复，缺少完整协议检查点时停止盲目重发。

提交后可以继续无依赖工作；await 后该 Session 的未配对调用只由完整结果续接。未实现跨历史分叉合并、其它领域工具或长期自动超时维护。P1 在原主体失去 workspace.write 后可能拒绝物理回执登记，本包未改变这条既有权限边界。

本方法直接调用 Run 应用入口，验证真实 DBOS 事务入队但不启动 worker 消费排队记录；不构成真实 worker SIGKILL/恢复证据。Git 文件操作使用私有临时目录，物理资源账本与 Runner 容量沿用旧支持边界。没有收费提供方请求、部署、Desktop 编译/原生、容量或人类验收。
