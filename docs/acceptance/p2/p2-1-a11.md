- 一个已结束的隔离方法因构建器前置门禁未启动 builder，原 unknown 报告在定向物理停止及临时库收尾后归档到原有有界存储，四份记录逐字节摘要不变。这是本方法收尾，不代表产品未知构建恢复能力。
- WSL 观测到墙钟回拨；方法只等待认证时间恢复，未调系统时间或放宽认证，不给出由墙钟计算的性能/可信时间结论。
- worker 退出时对共享存储的历史 journal 仍可能报告 cleanup_unconfirmed；本方法另以原 ResourceDispatcher 确认本轮 daemon/后代进程、组和瞬态占账释放。永久 16GiB backing/owner 仍保留，不能声称磁盘已回收或完整 worker 退出/恢复验收通过。
