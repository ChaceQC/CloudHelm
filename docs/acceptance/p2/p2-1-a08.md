## 覆盖与限制

Runner 方法使用真实 Linux 临时文件、真实源码 manifest 观察、Python 子进程编译及临时本机 HTTP 服务。为隔离验证，Docker 调用替换为本机 Python 子进程，只把固定容器源码根和本机端口映射到临时路径/端口；容器登记、controller、环境 spec 读取和原资源组合为夹具。HTTP 服务使用合成 notes 数据，不是实际 notes/FastAPI/数据库或 Docker 证据。成功与失败分别核对真实退出码 0/1/84、语法文件行号和 ready 503；超时由夹具触发，不能表示真实容器超时/停止验证。
