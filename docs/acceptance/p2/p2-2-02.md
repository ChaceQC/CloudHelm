## 支持边界

真实 HTTP 验证仅覆盖本机无数据库实例的两项 not-ready 检查。未对真实完整候选执行全部 50 项、真实进程重启或故障准备；这些准备须由受控执行方提供准确物理证据。合成事实的实库验证不能证明真实构建、制品运行或部署通过。

没有运行全量、收费模型、worker 恢复、真实远端部署、容量、Desktop 编译/原生或人工验收。受信生产者通过内部 Python 入口调用，未新增 Runtime/Gateway 自动验收工具。正式验收只支持已固定的参照方法；选择通过证据不接受工作项、不完结 Task、不批准 Release 或部署。

唯一新增表保存当前消费适用性与反向依赖；原报告、旧 accepted/完成及 Release 历史均不改写。变化同步有界传播，超过 128 条命中时拒绝整笔变化登记，不能据此认定影响分析完成。已开始远端步骤仍按原协议收束，原 grant 查询不生成新启动许可。

使用接口、准备证据及准确输入关系见[正式验收说明](../../development/p2-verification.md)。隔离数据库已由夹具清理，没有新增开发镜像；完整产品和人工验收状态保持各自原记录。
