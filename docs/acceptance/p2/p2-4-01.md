## 支持限制

当前实际 DNS/TLS、可信路线证据及允许预览槽的机器登记未在本轮取得；实际路线默认关闭。源代码的准备/观察/停止适配不等同于本轮真实受管容器链通过。首批仅固定 notes 配方与后端增量 HTTP；WebSocket/HMR/Worker 未开放。未知停止仍占账，保留磁盘独立计量。

本机 ASGI/上游关闭不证明外部 TLS 入口已断开，撤销没有独立确认或可信时基时仍待确认。没有测量或宣称 3 秒/2 秒/10 秒承诺。P2.4-02 还须在实际 Windows Edge/Tauri/WebView 等组合取得直接证据；本包不新增正式客户端支持或人工通过。
