## 支持边界

新 r2 开发指令与结构化交接复用 A03～A08 和原 Gateway/Operation。无进展是单 Run 的有界启发式：工具、参数与有效反馈相同才计重复，检查只排除明确的本次时钟及派生证据摘要；新源码、方法、失败或有用读取内容会重置计数。预算等边界可能先于无进展触发，未宣称识别所有语义无进展。

候选交接只指向当前输入及工作区下的实际已注册快照；交接摘要中的模型分析仍为说明，完整 diff/检查事实通过原工具历史核对。`submitted` delivery 引用对应本 Run 持久交接，独立验收、审查、Task 完成、Release 和部署继续由各自领域裁决。人类决策、无进展、预算及超时保留 paused/明确下一步，不自动批准、扩额或启动普通继续 Run；长工具沿原可靠等待续接。未知物理执行不因 Run 退出而释放资源。
