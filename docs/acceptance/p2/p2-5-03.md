## 支持限制

没有调用收费模型，没有对真实完整候选完成四阶段 50 项正式验收；实际实例、重启及故障准备仍须受控执行方提供。当前正式方法仍仅支持原固定参照 HTTP 修订；项目合并候选读取明确拒绝，不回退到活动工作区。验收事实来源须与原调用者匹配，不冒用另一主体的已登记来源。

没有新增 HTTP 或执行协议，没有重跑无关历史套件、Desktop 构建/原生、人类验收、部署、恢复或容量实验。隔离数据库/容器由原夹具清理；无本包开发镜像需要替代清理。旧候选与 A11 的真实模型证据保持各自原适用范围，不能作为本包真实独立验证通过证据。
