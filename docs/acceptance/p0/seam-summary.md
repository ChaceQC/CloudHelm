## 1. 范围和版本

实际环境、候选来源、许可证、解释器/锁文件、数据库镜像及工具链限制见 [组件基线](../../decisions/p0/component-baseline.md)。使用方法见 [隔离接缝说明](../../development/p0-seams.md)，契约见 [P0 契约草案](../../../packages/contracts/p0/README.md)。

本次仅运行 WSL 本机隔离接缝；没有业务软件、Desktop 原生、独立 Linux 交付机器、实际 DNS/TLS、产品权限或正式人类验收结论。probe 包元数据不是 CloudHelm 软件版本。正式输入和独立验收资产须由 P0.2 提供，生产许可/身份/可信误差及统一出口由 P0.3 决定。

## 3. 工作包与后续门禁

|接缝|实际可复用能力|薄适配/受阻边界|
|---|---|---|
|Runtime/Gateway|PydanticAI 消息、Deferred 批次、实际 SDK 工具事件及模型 Responses 接口|当前业务授权、费用、输入/结果引用与 Gateway 接线由业务层实现；供应商工具流的副作用/断流路径仍未覆盖|
|DBOS/业务状态|同库事务入队、async run_sync、稳定业务身份去重、单身份恢复、受控同版本 resume、队列与优先级|DBOS 保存原参数/错误，必须先裁剪；DBOS 队列不替代宿主资源账本，技术成功不替代业务结果|
|Hub/Remote Agent|实际 Compose 归一化；两环境保持制品/拓扑；loopback 在线 Ed25519 许可、SQLite 账本及真实子进程事实|仅临时合成 counter，正式身份、TLS、时间误差、资源准入、真实镜像/迁移和独立交付未证明|

用户在 s2a 使用日志中确认真实请求可见，并指出先前为同步请求；初始 18 次由 Agent.run 发出非流式请求。随后固定 C3 用实际 stream=true 取得 HTTP 200/text-event-stream、完整 SSE 和 PydanticAI 事件、response.completed=1，供应商 usage input=3543/output=11/total=3554。预登记为 2026-10-13T05:08:48Z，最终记录为 2026-10-13T05:08:53Z；provider response ID 和 x-request-id 均已持久追加，再次启动同 C3 的出站数为 0。供应商文本流只证明该模型流，不能代替 SDK-03 的副作用工具流/断流整卡证据。

P0.1-01 的隔离工程、版本清单、锁文件、启动与脱敏诊断已完成；P0.1-02～06 的有限切片已有真实观测，六卡保持各自完整出口状态；P0.1-07 完成三组隔离集成与专项报告，但 P0.2 尚未执行，首条参照与独立拓扑交叉核验未完成，不以隔离 fixture 替代它。

本次探测代码和固定断言由开发代理提供，用于 SDK 选型及接缝取证，不作为 P2 的独立正式验收资产。六卡实测的独立切片不自动放行产品对应入口；未支持或无法观测的能力维持阻断，P4 前本机应急入口保持关闭。

## 4. 输入和复核

最终候选的 [公共输入清单](input-set-r1.json) 保存 17 个 pyproject/uv.lock/Python pin、探测源码、隔离 Compose 和契约源的 SHA-256。`scripts/p0/input_manifest.py` 仅输出公开输入哈希，不读取认证配置。各卡的历史候选及方法保持其原支持范围，不把本清单追认为之前版本全部通过。改变代码、依赖、输入或环境时建立新候选和相应新证据；没有变化时不重复运行所有故障实验。

当前所有工作包原人日估算保持设计基线，本次实际墙钟区间和额外适配需求记录在 PROJECT_PROGRESS.md，不把并行代理运行时长换算为虚构人日。剩余产品适配和正式支持取证待估，P0/P1 统一出口再重估。
