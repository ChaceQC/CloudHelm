# 独立参照检查项目录

`check-catalog-r1.json` 是 `reference-http-checks-r1`，仅依据既有独立 HTTP 脚本及 manifest 整理，不读取参照候选实现。它显式列出全部 50 个检查 ID，包括 title 长度 1/120 的展开项，覆盖 baseline、seed、verify-persisted、not-ready 四种 phase 的原登记集合。它不改变断言或选例规则，不声明所有检查在单次运行中执行，也不产生通过或人工结论。

目录固定旧来源 InputSet 摘要、需求/方法修订、脚本及其它公开资产摘要、资产 bundle 摘要和检查数量；加载器固定目录自身的 SHA-256，沿用有界、无链接的公开文件读取。运行时不解析或执行脚本来发现检查 ID。候选工作区不能提供或替换此目录；公共 HTTP 请求不能选择资产路径。
