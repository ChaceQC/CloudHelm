## 本轮代码收尾的证据边界

归档总时限覆盖下载、OCI 核验/解包、classic 转换及 Docker CLI 调用；截止后的本地进程停止不能证明 daemon 内的未知副作用结束。原意图和占用保留，只读核对不得重传、加载或启动后续步骤。

归档成功补报必须有受信完成回执，绑定原 Operation、计划和步骤摘要，并重新核对实际归档与镜像。旧部分归档或缺少可信完成证明继续为 unknown。完整计划的纯核对只补报已有事实，全部步骤已经成功且回报确认后才关闭本地绑定；缺任何步骤或结果不明均保持原身份。

本轮定向方法与运行元数据在 [当前进度](../../../PROJECT_PROGRESS.md#2026-10-27p1-剩余收尾与-p2-入口核对) 更新；完成前不将实现意图记为验证通过。合成 OCI/daemon 回复方法只证明其覆盖的边界，不证明独立目标部署。

网络恢复后的只读核对确认原三份 OCI 长度及摘要、Hub pg_dump/roles 摘要均匹配，可以在适用性核对后复用。旧快照实际业务 head 为 `0008_p1_4_remote`，与当前源码 `0009_p1_5_sync` 不同。目标专属进程已停，原部分归档仍无完成凭据；未挂载的目标 SQLite 还含 WAL，不能只读主文件就声称已经核清完整账本。旧批准与计划期限过期，旧 profile 的 Hub 启动纪元不匹配。当前尚无受支持的同绑定 unknown 释放及准确新计划，不提前索取新摘要批准，也不把旧备份接入普通 worker 自动执行；下一入口是原身份收束与隔离核对方案。
