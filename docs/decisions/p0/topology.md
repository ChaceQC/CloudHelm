## 1. 设计目标与本次实际范围

D06 §2.1 的目标拓扑包括 Linux x86_64 Hub、Linux x86_64 开发 Runner 和独立 Linux x86_64 交付机器，并要求单独记录本机 WSL 开发环境。同机 light 与独立 Runner 使用不同的容量口径。总体设计 §7 将 Hub 的标准硬件基线定为 4 核、8 GB；同机 light 的常驻平台预留、系统及缓存、突发余量、开发执行共享预算分别为 2、1、1、4 GiB。该数值是设计/验收基线，不是本次观测得到的容量结论。

2026-10-13 的只读检查覆盖 Ubuntu-24.04 WSL2 与用户指定的 s2413 Linux 主机候选，当时将其登记为独立交付候选，没有部署 Hub 或注册 Runner。后续用户选择以第 1.1 节为准；本轮新事实见第 1.2 节，实际运行仍需路径、硬配额、网络和注册/执行证据。
