# CloudHelm HTML 界面方案

五套方案以 P1.5-01/02 和 D05 客户端行为为功能依据，使用本地内存数据。直接打开 [总览](p1-5-html/index.html) 即可使用，不需要 npm、Rust 或后端服务。原三套 Tauri example 已按用户要求删除，历史记录保留在项目进度中。

界面以对象数据、状态和操作为主，保留批准摘要、取消原因与执行未知等必要确认。

|方案|组织方式|入口|
|---|---|---|
|01 任务看板|以需要处理的事项为中心，按阻塞/待批准/推进/待提交分列，卡片展开上下文|[任务看板](p1-5-html/board.html)|
|02 部署航线|以环境变更为中心，沿起点、固定计划、执行和核对浏览交付|[部署航线](p1-5-html/voyage.html)|
|03 对象工作台|项目树、对象列表、详情与关联证据组成多栏对象浏览器|[对象工作台](p1-5-html/atlas.html)|
|04 事件卷宗|时间线区分命令、批准、执行与观察，从事件打开关联对象|[事件卷宗](p1-5-html/dossier.html)|
|05 命令中心|搜索优先，键盘命令与聚焦操作区配合，底部导航进入交付和连接恢复|[命令中心](p1-5-html/command.html)|

每套可进入任务与详情、Release、环境配置、固定部署计划/批准、部署跟踪、连接身份、快照事件及恢复场景。可创建并提交任务、核对完整摘要后批准、查询原 Operation、填写原因取消；命令接收不等同于业务完成，未知/停止待确认保留占用，计划批准不自动开始部署。

恢复场景包含离线只读、权限收回、事件缺口后重建快照、单 worker 重启、业务提交后检查点缺失、接收回执丢失、容量满与旧备份恢复门禁。这些按钮只改变本地展示，不连接真实 API，不启动模型或物理执行；刷新页面重置本页数据。配置只展示秘密引用字段名，不包含秘密值。

也可从仓库根目录在 Windows PowerShell 启动静态预览：

```powershell
python -X utf8 -m http.server 14215 --bind 127.0.0.1 --directory examples/p1-5-html
```

随后打开 <http://127.0.0.1:14215/index.html>。方向切换条用于比较五套原型；选定方案后再安排正式 Desktop 实现。浏览器原型不表示 P1.5 已开放、真实链路已接入或原生/人工产品验收通过。
